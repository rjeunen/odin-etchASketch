A bigger project to complete without that much help or info.

Create kind of an etch-a-sketch
it renders a 16 by 16 grid when the browser is started.
Whenever the user chooses a new grid size, the existing grid gets deleted and a new grid is created with the number of grid cells the user requests.

A grid larger then 100 by 100 is not possible.

improvements for later implementation:
